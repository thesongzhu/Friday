# Repository Reports Index

This directory contains repository-level reports, audits, coverage summaries,
test plans, and hygiene artifacts.

These files are evidence and diagnostics, not the primary source of truth for
current product behavior.

If a report conflicts with current behavior, prefer:

1. [`docs/current-source-of-truth.md`](../../current-source-of-truth.md)
2. [`docs/VISION.md`](../../VISION.md)
3. [`docs/reports/closeout/final-non-platform/latest.md`](../closeout/final-non-platform/latest.md)

Typical contents in this directory include:

- coverage and test matrices
- route and contract audits
- parity and hygiene reports
- enablement and gap summaries
