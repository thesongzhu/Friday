# QA Checklists

Shell:
- page switch does not reset conversation
- right rail context changes with current object
- collapse and resize behavior persists

Navigation:
- every capability is reachable within two levels
- mobile and desktop page ownership stays the same

States:
- loading, empty, error, partial, success all render with the correct semantic components

Critical flows:
- start task
- review result
- approve blocked action
- inspect workflow failure
- inspect provider issue
- inspect node issue

Content:
- primary labels are plain language
- evidence references appear wherever approvals or recovery are shown
