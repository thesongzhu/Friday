# Outsourcing Constraints

External implementers may:
- translate these blueprints into production-grade React/Vite components
- connect BFF endpoints to the defined view models
- extend primitive styling within the token system

External implementers may not:
- change first-level navigation ownership
- create a separate admin console
- split the right rail into a different chat product
- expose hidden internal capabilities as new pages
- collapse multiple state meanings into a single generic alert style

Escalation triggers:
- missing data dependencies
- disagreement with page ownership
- new capability that does not fit the registry
- a required action that cannot be expressed inside the shell model
