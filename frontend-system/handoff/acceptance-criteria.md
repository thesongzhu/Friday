# Acceptance Criteria

Delivery is acceptable only when all of the following are true:

Documentation:
- all 10 first-level pages have complete blueprints
- every non-Marketplace, user-meaningful capability has a primary and secondary surface
- every page defines desktop layout, mobile mapping, right-rail linkage, and all five state classes

System design:
- tokens, primitives, patterns, and page blueprints are clearly separated
- the right rail uses one shared conversation model
- no page requires a separate admin mode

Preview coverage:
- desktop shell preview exists
- mobile shell preview exists
- each first-level page has at least one preview sample

Implementation handoff:
- outsourcing teams do not need to decide navigation ownership
- outsourcing teams do not need to invent responsive behavior
- outsourcing teams do not need to invent state semantics
