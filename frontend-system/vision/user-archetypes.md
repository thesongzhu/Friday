# User Archetypes

## 1. New Operator

Profile:
- low setup tolerance
- task-focused
- needs confidence and clear next actions

Needs:
- a default home that explains current work
- obvious chat entry
- visible approvals and recovery steps
- plain-language status

## 2. Daily Manager

Profile:
- runs repeated work
- needs queue visibility and quick intervention

Needs:
- live status across workflows and automations
- retry, evidence, and audit visibility
- one-click jump from summary to detail

## 3. Builder

Profile:
- defines workflows, prompt flows, integrations, and runtime behavior

Needs:
- workflow builder entry
- integration and provider health
- runtime settings, memory inspection, diagnosis

## 4. Trust Owner

Profile:
- cares about tokens, secrets, grants, health, incidents, and risk

Needs:
- security center inside settings
- observability evidence trail
- clear separation between user-facing controls and internal-only mechanisms

## 5. Fleet Operator

Profile:
- runs distributed nodes, satellites, or paired devices

Needs:
- device health and pairing state
- sync lag and execution-node visibility
- clear escalation from node issue to diagnosis and recovery
