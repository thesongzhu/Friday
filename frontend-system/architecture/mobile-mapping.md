# Mobile Mapping

Global rules:
- desktop center content stacks vertically on mobile
- right rail becomes a drawer or fullscreen sheet
- keep the same conversation session and context model
- use sticky bottom actions for approval, retry, and run entry when helpful

Mapping by area:
- `Home`: summary, live work, approvals, recent results, packs, next actions
- `Chat`: fullscreen conversation with expandable activity strip
- `Assistant`: priority inbox first, evidence drawer second
- `Workflows`: list first, workflow detail or builder in stacked drill-in
- `Automations`: queue cards and schedule cards in one-column lists
- `Memory`: search first, result list second, detail in sheet
- `Integrations`: segmented switcher for Packs, Skills, Plugins, MCP, Channels
- `Observability`: incidents and health above audit detail
- `Fleet`: node list first, node detail second
- `Settings`: domain switcher plus stacked sections

Mobile constraints:
- no fixed three-column layouts
- no hidden approvals below long charts
- no hover-only affordances
