# Daily Memory

Use this directory for short-lived project notes that should influence the next few runs without becoming permanent repo policy.

Recommended pattern:

- one file per day: `memory/YYYY-MM-DD.md`
- short bullets only
- facts, blockers, recent decisions, and current focus
- no secrets or tokens

Keep durable facts in `context/MEMORY.md`.

Notes exported by the runtime under `.friday/exports/memory/` are managed automatically and should not be edited by hand.
