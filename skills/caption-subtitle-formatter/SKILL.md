# Caption & Subtitle Formatter

Formats captions and subtitles for readability, timing, and accessibility across videos.

## Features

- Line breaks for visual clarity
- Timing alignment with speech
- Readability optimization

## Instructions

- Format each line for maximum clarity
- Match timing cues to speech patterns
- Maintain readability standards
- Output caption text blocks with timing cues

## Constraints

- Avoid long, unbroken lines
- Keep captions clear and concise

Typical triggers:

- `format these captions`
- `create subtitles for this`
- `optimize these subtitles for readability`
- `format captions with timing`
