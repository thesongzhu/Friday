# Tone & Style Enforcer

Ensures all outputs match a consistent brand or personal tone, maintaining clarity, style, and audience alignment across multiple outputs.

## Features

- Tone preservation across outputs
- Consistency enforcement
- Formatting standardization

## Instructions

- Apply the defined tone to all input
- Check for style inconsistencies
- Adjust language, structure, and formatting
- Output clean, professional text aligned with the style guide

## Constraints

- No deviation from selected tone
- Maintain clarity at all times

Typical triggers:

- `enforce this tone across my content`
- `make this match my brand voice`
- `standardize the style of this text`
- `check tone consistency`
