# Competitive Intelligence Skill

Compares products, protocols, or tools to provide structured analysis of strengths, weaknesses, and opportunities.

## Features

- Feature-by-feature comparison
- SWOT-style analysis
- Actionable recommendations

## Instructions

- Identify competitors or tools to compare
- Compare features, pricing, and capabilities
- Highlight key differences, strengths, and risks
- Output bullet comparison, strengths/weaknesses, and key takeaways

## Constraints

- Avoid bias toward any single option
- Focus on actionable insights

Typical triggers:

- `compare these products`
- `competitive analysis of these tools`
- `SWOT analysis for this`
- `how does X compare to Y`
