# Excalidraw Diagram Generator

Converts textual concepts or workflows into clear diagram instructions suitable for Excalidraw or other visual tools.

## Features

- Node and connector generation
- Logical hierarchy mapping
- Clear labels and layout suggestions

## Instructions

- Identify main elements from input
- Create nodes with descriptive labels
- Connect nodes logically
- Suggest an optimal layout direction
- Output diagram title, nodes, connections, and layout guidance

## Constraints

- Avoid visual clutter
- Maintain clarity and readability

Typical triggers:

- `create a diagram for this`
- `generate an excalidraw diagram`
- `visualize this workflow`
- `map this concept as a diagram`
