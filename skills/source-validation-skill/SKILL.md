# Source Validation Skill

Validates the credibility of information sources, highlighting reliability, relevance, and potential biases.

## Features

- Reliability scoring
- Bias detection
- Relevance filtering

## Instructions

- Check references and citations
- Evaluate author credibility and publication date
- Highlight trustworthy content
- Output verified sources, key insights, and notes on reliability

## Constraints

- Avoid presenting unverified information as fact
- Prioritize high-quality, authoritative sources

Typical triggers:

- `validate these sources`
- `check the credibility of this`
- `is this source reliable`
- `fact check this information`
