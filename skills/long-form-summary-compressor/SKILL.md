# Long-Form to Summary Compressor

Condenses long text into concise summaries, keeping essential ideas intact for quick consumption and understanding.

## Features

- Key point extraction
- Bullet or paragraph output
- Simplifies dense material

## Instructions

- Identify main points from the input
- Remove redundancy and filler
- Produce a readable, actionable summary
- Support both concise paragraph and bullet point formats

## Constraints

- No missing critical information
- No filler content

Typical triggers:

- `summarize this`
- `compress this into key points`
- `give me a tldr`
- `condense this long text`
