# Structured Copywriting Skill

Generates high-impact copy with clear hooks, structured flow, and concise messaging for marketing, articles, and social media content.

## Features

- Strong opening hooks
- Sectioned content flow
- CTA inclusion
- Concise and readable output

## Instructions

- Craft an attention-grabbing opening
- Organize main points clearly with sections
- Include an actionable call-to-action
- Avoid unnecessary filler
- Output sections, bullet points, hooks, and conclusion

## Constraints

- Maintain readability
- Do not overcomplicate messaging

Typical triggers:

- `write copy for this`
- `create marketing copy`
- `write a social media post with a hook`
- `structured copywriting for this topic`
