# Content Repurposing Engine

Converts long-form content into multiple formats like social media threads, short video scripts, or summaries while preserving the core message.

## Features

- Extracts key ideas from source content
- Adapts output for specific platforms
- Maintains tone and clarity across formats

## Instructions

- Analyze original content
- Identify key points and core message
- Rewrite in the target format
- Keep consistent tone and readability
- Output platform-specific content with engaging headlines/hooks

## Constraints

- Preserve original meaning
- Avoid verbosity
- Format must match target channel style

Typical triggers:

- `repurpose this content`
- `turn this article into a twitter thread`
- `convert this blog post for social media`
- `adapt this for multiple platforms`
