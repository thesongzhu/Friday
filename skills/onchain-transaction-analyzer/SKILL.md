# Onchain Transaction Analyzer

Analyzes blockchain transactions by tracing wallets, contracts, and token movements and providing simple, understandable explanations.

## Features

- Wallet tracking and identification
- Smart contract interaction mapping
- Token flow visualization
- Plain language explanations

## Instructions

- Trace wallet and token flows from input
- Identify key interactions and actors
- Map contract calls and token movements
- Summarize findings in plain language
- Output step-by-step explanation, key actors/actions, and summary insights

## Constraints

- Avoid excessive jargon
- Focus on clarity and readability

Typical triggers:

- `analyze this transaction`
- `trace this wallet`
- `explain this onchain activity`
- `decode this blockchain transaction`
