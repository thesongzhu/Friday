# Skill Creator (Meta Skill)

Generates new AI skills in `.md` format, providing structured name, description, and instructions for future use.

## Features

- Generates skill metadata (name, description)
- Includes detailed instructions
- Outputs ready-to-use SKILL.md format

## Instructions

- Accept the input goal or capability description
- Define the skill's role, task, and process
- Structure output as a complete SKILL.md file
- Include features, instructions, constraints, and typical triggers

## Constraints

- Maintain clarity and consistency
- Ensure the generated skill is immediately usable

Typical triggers:

- `create a new skill`
- `generate a skill for this`
- `build a custom skill`
- `make a new SKILL.md`
