# Design Plan Review Checklist

## User Experience

- [ ] Primary user flow requires 3 or fewer steps
- [ ] Error states have clear recovery actions
- [ ] Loading states are shown for async operations
- [ ] Responsive behavior defined for mobile, tablet, desktop
- [ ] Accessibility: color contrast, keyboard nav, screen reader labels

## Information Architecture

- [ ] Navigation hierarchy matches user mental model
- [ ] Labels use user-facing language (not internal jargon)
- [ ] Empty states guide users toward the first action
- [ ] Destructive actions require confirmation

## Visual Design

- [ ] Consistent with existing design system / component library
- [ ] Spacing and alignment follow the grid
- [ ] Typography hierarchy is clear (headings, body, captions)
- [ ] Interactive elements have visible hover/focus/active states

## Feasibility

- [ ] Proposed components exist or have a clear build plan
- [ ] Data requirements are available from current APIs
- [ ] Performance budget considered for animations / heavy views
- [ ] Edge cases documented (long text, missing data, permissions)
