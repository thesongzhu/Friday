# Code Review Skill

Reviews code for bugs, inefficiencies, and adherence to best practices, providing actionable improvement suggestions.

## Features

- Error and bug detection
- Optimization recommendations
- Style and best practice enforcement

## Instructions

- Analyze code line by line
- Highlight errors, bugs, or inefficiencies
- Suggest concrete improvements with code examples
- Output issues found, suggested fixes, and optional summary

## Constraints

- Maintain accuracy in findings
- Avoid false positives

Typical triggers:

- `review this code`
- `find bugs in this code`
- `code quality check`
- `suggest improvements for this code`
