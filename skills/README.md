Bundled starter skills live here.

These skills ship with Friday as the default starter pack. They are discovered
from the bundled `skills/` root and are intended to be immediately usable on a
fresh local install without depending on the marketplace.

The pack now includes both local devops diagnostics and Friday-native
diagnosis/recovery reviews, so users can inspect runtime health, open issues,
repair readiness, and failed deploy recovery without generating a new skill.
