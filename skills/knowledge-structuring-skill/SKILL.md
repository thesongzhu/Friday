# Knowledge Structuring Skill

Organizes unstructured information into clear frameworks, bullet points, or structured notes for easier understanding and application.

## Features

- Categorizes ideas into logical groups
- Creates clear hierarchy
- Bullet formatting for readability

## Instructions

- Identify major topics from input
- Group related ideas together
- Present content clearly and concisely
- Output structured framework, key points, and optional notes

## Constraints

- Avoid ambiguity
- Maintain readability

Typical triggers:

- `organize this information`
- `structure these notes`
- `turn this mess into structured knowledge`
- `categorize and organize this`
