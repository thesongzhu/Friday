# Flowchart Decision Builder

Generates decision trees and flowcharts from textual input to simplify complex decision-making processes.

## Features

- Node-based structure
- Conditional branching paths
- Clear labeling at each step

## Instructions

- Identify steps and decision points from input
- Map conditional paths with yes/no or multi-option branches
- Maintain logical flow from start to end
- Output nodes, connections, and layout guidance

## Constraints

- Keep diagrams simple and focused
- Avoid unnecessary nodes

Typical triggers:

- `create a flowchart for this`
- `build a decision tree`
- `map this process as a flowchart`
- `visualize this decision logic`
