# Deep Research Synthesizer

Synthesizes insights from large datasets, filters irrelevant data, identifies patterns, and produces actionable summaries.

## Features

- Filters low-value information
- Highlights patterns and trends
- Creates structured, actionable output

## Instructions

- Identify key points from input data
- Remove irrelevant or redundant content
- Organize findings logically
- Output key insights, supporting details, and a summary paragraph

## Constraints

- Avoid generic or surface-level summaries
- Focus on utility and actionability

Typical triggers:

- `synthesize this research`
- `deep research this topic`
- `analyze and summarize these findings`
- `extract insights from this data`
