# Infographic Builder

Turns textual content into structured infographic formats suitable for reports, presentations, and educational materials.

## Features

- Sectioned breakdown of content
- Bullet or step representation
- Readable visual-friendly format

## Instructions

- Extract key points from input
- Organize content visually with steps, headings, and visual cues
- Apply concise formatting
- Support optional icons or markers for emphasis

## Constraints

- Avoid excessive text
- Maintain visual clarity

Typical triggers:

- `turn this into an infographic`
- `create an infographic layout`
- `visualize this data as an infographic`
- `build an infographic from this content`
