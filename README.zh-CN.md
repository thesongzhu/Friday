> **Friday 不是模型，也不是聊天框。** “大脑”是*你本来就在付费*的云 AI（BYOK：Codex、Claude、DeepSeek……）。Friday 是**指挥它们干活的那个老板**——而老板、加上你的钥匙、你的数据、你的记忆，全都待在你自己机器上。**老板归你；大脑只是你租来的。**

## Friday 是什么？

玩转 AI agent 的窍门，不是你自己整天去 prompt 它们——而是搭一条**替你去 prompt 它们的闭环**。Friday 就是那条闭环，做成了产品、还做安全了：

> **找到活 → 派给一个 AI → 查它是不是真干完了 → 记下完成了什么 → 挑下一件事**——让系统去催 agent，你就不用催了。

底层它把 Codex、Claude、DeepSeek 当一支**按量计费的班子**来使——便宜模型负责想和规划，贵的干重活——一路留好票据，碰到危险的就先按下暂停、等你说走。

## 闭环怎么运作

```
        你的目标
           │
           ▼
   路由 ── 这一步挑一个 AI （你可以改派）
           │
           ▼
   执行 ── 受治理：危险步骤停下等你批准
           │
           ▼
   验证 ── 证明它真干完了 （别信“我做完了”）
           │
           ▼
   记忆 ── 候选 → 你确认 → 它记住
           │
           └──────────────► 下一步
```

别人都跳过的那条腿是**验证**。一个给自己批改作业的 agent，绝对会偷工减料——所以在 Friday 里，“完成”必须**附一张回执**。模型说一句*“好了”*、或者进程悄悄退出了，本身都不算数。

还有两点让它不像个傻调度器：你的目标含糊，Friday 会**反问你到底想要啥**，而不是瞎猜——而且问清楚之前一个 token 都不烧；当一件活儿既要写码、又要做大局综合，它能让一个模型先写码、**等它证明干完了**，再把另一个模型叫进来。

## 它的不同之处（也是难被复制之处）

Codex 和 Claude 各塞给你一个很强的 agent。可它们谁都不会替你去管*另一个*，也不会把控制权放到你这边。Friday 站在它们上面一层——跨厂商、在你自己机器上——带着几条**焊死在构造里**、而不是同一个程序随手就能给自己翻的开关的保证：

- **我们压根没给 Friday 发笔。** 它握着用来*核对*你签名的钥匙，却没有用来*写*签名的那把——所以碰到危险动作，它伪造不出你的“同意”；点头这件事，只能你亲手在自己设备上离线做。
- **模型没法替自己的危险动作放行。** 纯只读的事根本不用你点头，但任何会改动世界、或闻着就危险的动作，在内核里只可能落到*需要你批准*或*拒绝*，永远不会是*行，去吧*。而且 agent 盖不了自己副作用的章。
- **“完成”绝不是模型一句话说了算。** 一个任务想翻成“完成”，除非真把证明回执别在它的记录上——这是在数据库底层强制的，再聪明的代码路径也绕不过去。没回执，就没完成。
- **没有哪条真记忆是背着你存下的。** Friday 把事实先当*候选*飘着；你不点头，它就熬不成真记忆——所以被投毒的“事实”只能干躺着、伤不了人。而它召回东西时，只认你名下的、还先把秘密擦干净了，才让模型看到。
- **不搞偷偷换模型那一套。** Friday 在花一分钱*之前*，用一个又快又免费、零 token 的决策挑模型；万一不得不切到备用模型，账单也老老实实写清楚到底是哪个模型回答的。它绝不悄悄换个别的、再甩给你一笔糊涂账。
- **防篡改是故意设计的。** 每一个经路由的 agent 回合都记成一条全有或全无的条目——谁、干了啥、花了多少——写进哈希链式的审计日志，悄悄改过去？链当场就断给你看。

这正是单厂商工具永远不会替你补上的那道缝：**一个中立的裁判，跨着厂商，站在你这边。**

## 为什么这么建

编程 agent 强得吓人、还强得飞快——但长活儿一上来它们照样撞墙，而且会乐呵呵地偷工减料、或者谎称干完了其实没干。2026 年的转向叫 **loop engineering（闭环工程）**：别再用手一条条 prompt agent，去搭那套系统——它找活、派活、**查活**、记下完成了啥、挑下一件。Friday 把这想法里缺的那几块，真做了出来：

- **验证才是决胜的那一手。** 给自己打分的 agent 信不得——所以“完成”必须带证据，不是拉个钩。这是大多数工具跳过的部分，也正是 Friday 围着它建的部分。
- **治理得在你这一侧的桌子上。** 那些恐怖故事都有案可查——记忆被悄悄投毒、私密数据发去了不该去的地方、花费失控、一条破坏性命令。所以批准、上下文护照、计量、审计，全活在*你的*内核里，而不是某家厂商的云上。
- **跨厂商才是重点。** 每个厂商都给你一个很强的 agent，对管别家则毫无兴趣。一个中立层、在你机器上调度它们、控制权在你手里——这就是它们谁都不会去填的缝。
- **模型是租的，不是娶回家的。** Friday 故意不做成一个模型。模型每隔几个月就换一茬；真正留得下的价值是外面那层 harness——路由、验证、记忆、治理——而这层归你。

## 它正在长成的样子

一个住在你手机和桌面上的私人 AI 参谋长：

- 在聊天里给它一个目标；它规划、把活儿摊给多个模型，还**把它挑了谁摆给你看、让你能推翻**。
- 危险步骤变成一张**你一键签的卡**；安全的直接做掉。你还有个**信任旋钮**——往上拨，一次预批一批低风险的活；往下拨，每步都确认。不可逆的事永远会问你。
- 它**被设计成越用越能懂你**——把干完的活攒成对你的偏好、和你那个世界的感觉，等*你*确认之后，本就是要悄悄给后续运行上色的（这条腿现在还没点亮；反射类的另拴一根受治理的绳、单独管）。
- **skill 欢迎，但拴着绳**：带一个审过的 skill 来、签名把它打开，而且只有你为这一次具体用法签了字它才跑——还关进它自己的小沙箱。Friday 不替你写 skill；它只治理你带来的那些。
- 每一个 agent——**以及它拉起来的每一个小弟**——都被设计成跑在一张可撤销、带花费/次数/工具上限的信任授权里，孩子的权限永远不会比父亲*更宽*。
- 它能在你写代码时从旁看着、从你的渠道（Telegram……）接活、接手定时任务——全在同一套规矩底下。

你自始至终都是那个老板：**大脑是租的，控制器是你的。**

## 原则

**本地优先的内核 · BYOK · 批准优先 · 人类掌控 · 证据兜底**

> 这里的*本地优先*指**控制器、你的钥匙、你的数据、你的记忆**都在你机器上——模型本身是你接入的云 API。Friday 是本地的**内核**，不是本地模型。

## 状态

Friday 是一个 **public v1 local candidate**，通过 npm / 源码发布。引擎和安全基质——目标→工作脊柱、路由、治理、计量、审计、封口传输——都已就位，钥匙你自带。把丑话说前头（诚实是整件事的根）：上面那些保证，是它*今天*这副构造的属性；而其中的运行时行为，目前只在内部 / 自检流量上跑过，**还没碰过真实用户负载**，更自治的那些则默认关闭、以 dark 形态出货。能力获取和自我升级是**受审查门控的进行中工作**，不是全自动驾驶的承诺。Friday 做它能安全做的事，**该需要你时清楚地停下**，并且总把票据留好。
